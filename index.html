Reading this map
Slope: green = flat, yellow = moderate, red = steep (Esri default ramp). Aspect: color wheel = compass direction the slope faces, gray = flat.
Ownership: USFS = light green, BLM = tan, private/other = white.

Not included
Meadows/openings can be read from Vegetation Type (herbaceous = open). Bench topography and beetle-kill staging aren't available as live public GIS layers, so they aren't modeled here — read those off the slope + hillshade + imagery by eye.
